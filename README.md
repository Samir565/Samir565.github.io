## 🚀 How to Run Locally

### Option A: Pure Node.js (Zero Dependencies)
Run this single command in your terminal:
```bash
node server.js
```
Open **`http://localhost:3000`** in any browser.

### Option B: Double-Click
You can also directly double-click `index.html` in File Explorer and it will open in any browser immediately without a server.
